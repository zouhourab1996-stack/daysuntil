How to use these comparisons

Each comparison exists to answer one question: given two or more products in the same category, which one should you actually buy. The tables put the score next to the price deliberately, because a higher score is only worth paying for if the thing it is scoring is something you will use.

Start with the "best for" column rather than the score. If the row that describes your situation is not the highest-scoring product, buy the one that matches your situation. Then check the price column, and finally read the caveats — every comparison here carries a section on what we could not verify, and it is the part worth reading before you spend.

What makes a comparison fair

Every product in a table went through the same rubric, on the same scale, with the same weights. Nothing is scored against a different standard because it is cheaper, newer, or pays a higher commission. Where a comparison includes a product we have not tested hands-on, that is stated on the page.

The other thing we try to do is include the option nobody asked about. Several comparisons here name a cheaper alternative that beats both headline products for a specific use, and it would be easy to leave it out because it pays less. It is in there.
